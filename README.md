# Android and systems research

Maintained by Syldegil. Experimental source releases, with bounded evidence and explicit limitations. No APK, kernel image, firmware, personal configuration or signing key is distributed.

| Project | Content | Evidence and limits |
|---|---|---|

| [android17-microg-integration-lab](https://github.com/Syldegil/android17-microg-integration-lab) · [v0.1.0](https://github.com/Syldegil/android17-microg-integration-lab/releases/tag/v0.1.0) | Restricted signature policy and App Links/RKP/CT experiments | 23 JVM +7 Python; emulator history separate; no installable ROM |
| [nothing-phone3-kernel-compat](https://github.com/Syldegil/nothing-phone3-kernel-compat) · [v0.1.0](https://github.com/Syldegil/nothing-phone3-kernel-compat/releases/tag/v0.1.0) | OEM BTF/CRC research tools and validation protocol | 12 host fixtures; B4.1 historical only; complete kernel build not qualified |

Each project provides English/French introductions, reproduction, evidence, privacy, provenance and limitations. Historical results are not counted as fresh tests. A fixture, checksum or brief observation does not prove universal compatibility, security or stability.
