# Recherches Android et systèmes

Index des sept préversions de sources maintenues par Syldegil. Voir [le tableau des projets et versions](README.md). Chaque dépôt distingue essais actuels, observations historiques et limites. Aucun APK, firmware, noyau à flasher, configuration personnelle ni clé de signature.

Les versions publiques ne remplacent pas automatiquement les applications privées. L’émulation ne qualifie pas le matériel, et les fixtures ne prouvent pas le partage réseau Android. Les recettes complètes noyau et transcription restent à qualifier. [Confidentialité](PRIVACY.md) · [Provenance](PROVENANCE.md).
